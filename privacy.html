Privacy Policy

This policy describes Orange Pi Backups, a personal rclone-based backup utility controlled by its operator.

Data accessed and purpose

The utility accesses Google Drive only after the account owner grants OAuth authorization. It processes backup file names, identifiers, sizes, checksums and other file metadata to upload and verify backup archives. Archives can contain saved Minecraft worlds, player data, server settings and management configuration. These data are used for backup and restoration.

Permissions and storage

The OAuth Drive permission used by rclone allows broad access to the authorized account’s files. The scheduled utility is configured to use a dedicated backup folder. OAuth credentials are stored in private configuration files on the operator’s server. Backup archives are stored on that server and in the operator’s Google Drive.

Sharing and use

The utility does not sell backup contents or Google user data, use them for advertising, or use them to train AI models. The scheduled utility does not make backup archives publicly accessible. Google processes files as the chosen cloud storage provider under its own applicable terms and privacy policy.

Retention and deletion

The newest complete backup is kept locally. Older local copies are deleted only after a newer complete local backup exists and their cloud upload has been verified. Cloud archives remain until the operator deletes them. Failed uploads leave the local files in place.

The account owner may revoke authorization in their Google Account security settings and delete archives from Google Drive. Revoking access stops future authorized operations; it does not automatically remove existing backup files.

This website and contact

This informational website contains no login form, analytics scripts or advertising integrations. It is intended for GitHub Pages hosting, whose normal hosting data practices are described in the GitHub Privacy Statement.

For questions or deletion requests, contact the operator using the support email shown on the Google OAuth consent screen.
