Orange Pi Backups

Orange Pi Backups is a personal backup utility operated on a private Orange Pi server. It uses rclone and the Google Drive API to store the operator’s Minecraft server backups in the operator’s own Google Drive account.

What the application does

The scheduled utility creates a daily local backup of the Minecraft server and its management configuration. After a newer backup is available, it uploads older backup archives to a dedicated Google Drive folder and verifies their size and checksums before removing the older local copies.

Google Drive access

Google Drive access is authorized by the account owner through Google OAuth. The utility requests the Drive scope used by rclone, which can grant broad file access. The scheduled backup code uses a dedicated backup folder. It does not provide a public file-sharing service.

This is a personal application, not a service offered to the public. Authorization credentials and backup contents are stored on the private server and in the operator’s authorized Google Drive storage, not on this website.

Read the Privacy Policy and Terms of Use. For questions, contact the operator using the support email displayed on the Google OAuth consent screen.
